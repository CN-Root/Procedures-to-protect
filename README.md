# Procedures to protect
Procedures to protect 是一款专为 Windows 平台设计的轻量级进程守护软件，旨在帮助用户实时监控和保护关键进程的稳定运行，防止进程被意外终止或恶意关闭。<br/>
软件通过持续检测指定的进程状态，自动重启异常退出的程序，保障关键服务和应用的高可用性，适用于各种需要进程稳定运行的场景，如服务器管理、后台任务守护及安全防护等。

<ui>主要功能：
  <li>实时监控进程状态，自动识别进程异常退出</li>
  <li>自动重启关键进程，保证系统关键服务持续运行</li>
  <li>配置简便，支持自定义守护的进程列表</li>
  <li>资源占用低，轻量级设计，不影响系统性能</li>
</ui>

<br/>

<ui>适用场景：
  <li>服务器和工作站关键进程守护</li>
  <li>后台服务和任务管理</li>
  <li>防止进程被恶意关闭</li>
  <li>任何需要保证进程稳定性的场景</li>
</ui>

<br/>

  <li>支持平台：Windows 全版本</li>

</ui>
